# Spec: OCM 等高线图层

## REQ-01: 坐标转换
- GCJ-02 经纬度 **必须** 可转换为 WGS-84 经纬度，精度在 1 米以内
- 瓦片索引 (z, x, y) **必须** 可与经纬度互转
- 坐标转换 **必须** 为纯函数（相同输入 → 相同输出）

## REQ-02: OCM 瓦片加载
- 导航/预览地图 **必须** 可叠加 OCM 瓦片图层
- OCM 瓦片 URL 模板：`tile.opencyclemap.org/{z}/{x}/{y}.png`
- zoom 限制 0-18，超出范围不请求
- 网络失败时瓦片区域透明，不影响底图

## REQ-03: 图层切换
- 地图右下角 **必须** 有图层切换浮动按钮
- 点击 **必须** 弹出选择器：标准地图 / 等高线叠加
- 切换 **必须** 实时生效
- 导航中切换 **必须** 不影响导航状态

## REQ-04: 导航 + 预览双重集成
- `AMapNavigationView` **必须** 支持图层切换
- 路线详情预览地图 **必须** 支持图层切换
- 两处共用一个 `MapLayerToggle` 组件
